# Настройка пользователя 1С:УНФ для HTTP API

## Цель

Настроить пользователя в 1С:УНФ, чтобы он мог авторизоваться через Basic Auth при обращении к HTTP-сервисам (OData, SiteExchange, кастомные HTTP-сервисы).

---

## Шаг 1: Запуск 1С:Предприятие

### 1.1 Откройте список баз 1С

Нажмите **Win + R**, введите:
```
"C:\Program Files (x86)\1cv8t\8.5.1.1150\bin\1cv8t.exe"
```

Или найдите ярлык **"1С:Предприятие (учебная версия)"** на рабочем столе.

### 1.2 Выберите базу УНФ

В списке баз найдите **"SmallBusinessEduc2"** (или как она у вас названа).

Если базы нет в списке — добавьте:
1. Нажмите **"Добавить"**
2. Выберите **"Добавление в список существующей информационной базы"**
3. Укажите путь: `C:\1C\SmallBusinessEduc2`
4. Нажмите **"Далее"** → **"Готово"**

### 1.3 Запустите в режиме "Предприятие"

Выберите базу → нажмите **"1С:Предприятие"** (не Конфигуратор!)

---

## Шаг 2: Вход в систему

### 2.1 Выбор пользователя

При запуске может появиться окно выбора пользователя:
- Выберите **"Администратор"**
- Пароль оставьте **пустым** (если не установлен)
- Нажмите **"Войти"**

Если окно не появилось — значит вход выполнен автоматически.

---

## Шаг 3: Открытие настроек пользователей

### 3.1 Перейдите в раздел "Администрирование"

В верхнем меню нажмите:
```
Администрирование → Настройки пользователей и прав → Пользователи
```

**Или** (в зависимости от версии УНФ):
```
Администрирование → Пользователи
```

### 3.2 Откроется список пользователей

Вы увидите таблицу с пользователями. Найдите **"Администратор"**.

---

## Шаг 4: Редактирование пользователя "Администратор"

### 4.1 Откройте карточку пользователя

Дважды кликните на **"Администратор"** или нажмите **"Изменить"**.

### 4.2 Настройка аутентификации

В карточке пользователя найдите раздел **"Аутентификация"**.

Установите галочки:

| Параметр | Значение | Описание |
|----------|----------|----------|
| ✅ **Аутентификация 1С:Предприятия** | Включена | Основной способ входа |
| ✅ **Пароль** | `123456` (или ваш пароль) | Установите пароль |
| ✅ **Показывать в списке выбора** | Включена | Пользователь виден при входе |

**Важно:** Учебная версия 1С требует, чтобы пароль был **не пустым** для HTTP-доступа.

### 4.3 Установка ролей

Перейдите на вкладку **"Роли"** или **"Права доступа"**.

Убедитесь, что у пользователя есть роли:
- ✅ **Полные права** (или аналог)
- ✅ **Администрирование**
- ✅ Доступ к **HTTP-сервисам** (если есть такая роль)

### 4.4 Сохраните изменения

Нажмите **"Записать и закрыть"**.

---

## Шаг 5: Перепубликация базы на веб-сервере

### 5.1 Откройте публикацию

В 1С:Предприятие перейдите:
```
Администрирование → Публикация на веб-сервере
```

**Или** (если нет такого пункта):
```
Сервис → Публикация на веб-сервере
```

### 5.2 Настройка публикации

В открывшемся окне:

- **Веб-сервер**: `Apache 2.4`
- **Директория**: `C:\Apache24\htdocs\unf`
- **Имя информационной базы**: `unf`

**Важные галочки:**
- ✅ **Публиковать тонкий клиент и веб-клиент**
- ✅ **Публиковать Web-сервисы**
- ✅ **Публиковать HTTP-сервисы**
- ✅ **Публиковать OData интерфейс**

### 5.3 Выполните публикацию

Нажмите **"Опубликовать"**.

Дождитесь сообщения **"Публикация выполнена успешно"**.

### 5.4 Перезапустите Apache

Откройте командную строку от администратора и выполните:
```cmd
C:\Apache24\bin\httpd.exe -k restart
```

Или перезапустите службу Apache2.4 через **services.msc**.

---

## Шаг 6: Проверка доступа

### 6.1 Проверка через браузер

Откройте в браузере:
```
http://localhost:8090/unf/odata/standard.odata/
```

Должно появиться окно авторизации. Введите:
- **Логин**: `Администратор`
- **Пароль**: `123456` (или тот, что установили)

### 6.2 Проверка через curl

Откройте командную строку и выполните:
```cmd
curl -u "Администратор:123456" "http://localhost:8090/unf/odata/standard.odata/"
```

Должен вернуться JSON с метаданными OData.

### 6.3 Проверка заказов

```cmd

curl -u "Администратор:123456" "http://localhost:8090/unf/odata/standard.odata/Catalog_ЗаказыПокупателей"
```

**Важно:** В учебной версии 1С имена объектов могут отличаться. Проверьте через `$metadata`:
```cmd
curl -u "Администратор:123456" "http://localhost:8090/unf/odata/standard.odata/$metadata"
```

## Шаг 7: Настройка Next.js

После успешной настройки 1С, обновите `.env.local`:

```env
# 1С:УНФ (локальная учебная версия)
ONE_C_BASE_URL=http://localhost:8090/unf/odata/standard.odata
ONE_C_USERNAME=Администратор
ONE_C_PASSWORD=123456
```

## Возможные проблемы

### Проблема: "При используемой лицензии допустимы только пустые пароли"

**Решение:** Учебная версия 1С ограничивает использование паролей. Попробуйте:
1. Оставить пароль **пустым**
2. Использовать **аутентификацию операционной системы**
3. Или создать нового пользователя без пароля

### Проблема: 403 Forbidden после настройки

**Решение:**
1. Проверьте, что Apache перезапущен
2. Проверьте права на папку `C:\Apache24\htdocs\unf`
3. Убедитесь, что `default.vrd` обновлён после публикации

### Проблема: 401 Unauthorized

**Решение:**
1. Проверьте логин/пароль
2. Убедитесь, что пользователь имеет права на доступ к OData
3. Проверьте, что аутентификация 1С:Предприятия включена

## Альтернатива: Создание отдельного пользователя для API

Вместо использования "Администратор", создайте специального пользователя:

1. **Администрирование → Пользователи → Создать**
2. **Имя**: `api_user`
3. **Пароль**: `api_password`
4. **Роли**: только необходимые (например, "Продажи", "Чтение заказов")
5. **Аутентификация 1С:Предприятия**: ✅

Это безопаснее, чем использовать администратора.
