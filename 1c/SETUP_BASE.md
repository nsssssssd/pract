# Пошаговая инструкция: создать базу 1С с заказами и выгрузкой в JSON

Эта инструкция подходит для **1С:Предприятие 8.3** с управляемыми формами. Мы создадим пустую конфигурацию с минимальным набором объектов: номенклатура, контрагенты, заказы покупателей. Затем сделаем внешнюю обработку, которая выгружает заказы в `orders.json`.

---

## Шаг 1. Создать новую информационную базу

1. Открой **1С:Предприятие 8.3**.
2. В окне запуска нажми **Добавить**.
3. Выбери **Создание новой информационной базы** → **Далее**.
4. Выбери **Создание информационной базы без конфигурирования** → **Далее**.
5. Укажи имя базы, например `ЗаказыДляСайта`.
6. Выбери тип размещения **На данном компьютере или на компьютере в локальной сети**.
7. Укажи путь к папке, где будет храниться база, например:
   ```
   C:\1C\Bases\ЗаказыДляСайта
   ```
8. Нажми **Готово**.

После создания базы открой её в режиме **Конфигуратор**.

---

## Шаг 2. Создать конфигурацию

При первом открытии конфигуратора увидишь пустое дерево конфигурации. Нужно включить возможность изменений.

1. В меню выбери **Конфигурация → Открыть конфигурацию** (или нажми `Ctrl + Shift + C`).
2. Появится дерево объектов: справочники, документы, регистры и т.д.

---

## Шаг 3. Создать справочник «Номенклатура»

1. В дереве конфигурации найди **Справочники**.
2. Правой кнопкой → **Добавить**.
3. Вкладка **Основные**:
   - **Имя**: `Номенклатура`
   - **Синоним**: `Номенклатура`
   - **Представление объекта**: `Номенклатура`
4. Вкладка **Данные**:
   - Длина наименования: `150`
   - Длина кода: `9`
   - Тип кода: `Число`
5. Нажми **Записать и закрыть**.

> Справочник уже содержит стандартные реквизиты: Наименование, Код. Этого достаточно.

---

## Шаг 4. Создать справочник «Контрагенты»

1. Правой кнопкой на **Справочники** → **Добавить**.
2. Вкладка **Основные**:
   - **Имя**: `Контрагенты`
   - **Синоним**: `Контрагенты`
3. Вкладка **Данные**:
   - Длина наименования: `150`
   - Длина кода: `9`
   - Тип кода: `Число`
4. Добавь реквизит:
   - Правой кнопкой на **Реквизиты** → **Добавить**.
   - **Имя**: `Телефон`
   - **Тип**: `Строка`, длина `20`
5. Нажми **Записать и закрыть**.

---

## Шаг 5. Создать перечисление «СтатусыЗаказов»

1. В дереве конфигурации найди **Перечисления**.
2. Правой кнопкой → **Добавить**.
3. Вкладка **Основные**:
   - **Имя**: `СтатусыЗаказов`
   - **Синоним**: `Статусы заказов`
4. Добавь значения:
   - Правой кнопкой на **Значения перечисления** → **Добавить**.
   - Значение 1: **Новый**
   - Значение 2: **ВРаботе**
   - Значение 3: **Подтвержден**
   - Значение 4: **Отправлен**
   - Значение 5: **Выполнен**
   - Значение 6: **Отменен**
5. Нажми **Записать и закрыть**.

> В обработке статус будет выгружаться как строка, поэтому на сайте увидишь: Новый, В работе, Подтверждён и т.д.

---

## Шаг 6. Создать документ «ЗаказПокупателя»

1. В дереве конфигурации найди **Документы**.
2. Правой кнопкой → **Добавить**.
3. Вкладка **Основные**:
   - **Имя**: `ЗаказПокупателя`
   - **Синоним**: `Заказ покупателя`
   - **Представление документа**: `Заказ покупателя`
4. Вкладка **Число**:
   - Длина номера: `11`
   - Тип номера: `Число`
   - Периодичность: **В пределах года**
5. Вкладка **Движения**:
   - ничего не выбирай (у нас нет регистров)
6. Вкладка **Проведение**:
   - Установи галочку **Проведение разрешено**.

### Добавить реквизиты шапки

Перейди на вкладку **Данные**.

1. Добавь реквизит **Контрагент**:
   - **Имя**: `Контрагент`
   - **Тип**: `СправочникСсылка.Контрагенты`
2. Добавь реквизит **АдресДоставки**:
   - **Имя**: `АдресДоставки`
   - **Тип**: `Строка`, длина `500`
3. Добавь реквизит **Статус**:
   - **Имя**: `Статус`
   - **Тип**: `ПеречислениеСсылка.СтатусыЗаказов`

### Добавить табличную часть «Товары»

1. Правой кнопкой на **Табличные части** → **Добавить**.
2. **Имя**: `Товары`
3. Добавь реквизиты табличной части:
   - **Номенклатура**: тип `СправочникСсылка.Номенклатура`
   - **Количество**: тип `Число`, длина `15`, точность `3`
   - **Цена**: тип `Число`, длина `15`, точность `2`
   - **Сумма**: тип `Число`, длина `15`, точность `2`
4. Нажми **Записать и закрыть**.

### Настроить форму документа

1. Открой документ `ЗаказПокупателя`.
2. Перейди на вкладку **Формы**.
3. Нажми **Добавить** → выбери **Форма документа**.
4. В мастере формы оставь всё по умолчанию и нажми **Готово**.
5. В конструкторе формы увидишь реквизиты шапки и табличную часть.
6. Добавь поле **Сумма документа**:
   - В дереве элементов формы добавь поле.
   - Путь к данным: `Объект.Товары.ИтогСумма` или создай вычисляемое поле.
   - Проще: в свойствах табличной части включите **Подвал** и выведите итог по колонке **Сумма**.
7. Нажми **Закрыть** и сохрани.

---

## Шаг 7. Обновить конфигурацию БД

1. В меню выбери **Конфигурация → Обновить конфигурацию БД** (или `F7`).
2. Если появится предупреждение о необходимости реорганизации — нажми **Принять**.
3. Дождись завершения.

---

## Шаг 8. Заполнить тестовые данные

1. Запусти базу в режиме **1С:Предприятие**.
2. Создай несколько номенклатур:
   - **Операции** → **Справочник Номенклатура** → **Создать**.
   - Например: «Красные тюльпаны», «Букет Весна».
3. Создай контрагента:
   - **Операции** → **Справочник Контрагенты** → **Создать**.
   - Имя: `Исупов Константин`
   - Телефон: `+7 908 107-41-45`
4. Создай документ «Заказ покупателя»:
   - **Операции** → **Документ Заказ покупателя** → **Создать**.
   - Контрагент: выбери созданного.
   - Адрес: `ул. Примерная, д. 1`
   - Статус: **Новый**
   - В табличную часть добавь товары с количеством и ценами.
   - Нажми **Провести и закрыть**.

---

## Шаг 9. Создать внешнюю обработку

1. Вернись в **Конфигуратор**.
2. В меню выбери **Файл → Новый → Внешняя обработка**.
3. В окне внешней обработки заполни:
   - **Имя**: `ВыгрузкаЗаказовВJSON`
   - **Синоним**: `Выгрузка заказов в JSON`

### Добавить управляемую форму

1. В дереве внешней обработки правой кнопкой на **Формы** → **Добавить**.
2. Выбери **Управляемая форма**.
3. В мастере:
   - Имя формы: `Форма`
   - Нажми **Далее**, затем **Готово**.

### Добавить реквизиты формы

1. В дереве реквизитов формы правой кнопкой → **Добавить**.
2. Создай реквизиты:
   - **ПутьКФайлу**: тип `Строка`, длина `500`
   - **ДатаНачала**: тип `Дата`, состав даты **Дата**
   - **ДатаОкончания**: тип `Дата`, состав даты **Дата**
   - **СтатусЗаказа**: тип `Строка`, длина `50`

### Добавить элементы формы

Перетащи реквизиты на форму из дерева реквизитов:

1. **ПутьКФайлу** → поле ввода.
2. **ДатаНачала** и **ДатаОкончания** → поля ввода.
3. **СтатусЗаказа** → поле ввода (можно оставить пустым для выгрузки всех).

### Добавить команду

1. В дереве объектов формы правой кнопкой на **Команды** → **Добавить**.
2. **Имя**: `ВыгрузитьЗаказы`
3. **Действие**: выбери **Клиентскую процедуру**.
4. Перетащи команду на форму как кнопку.

### Вставить код

1. В свойствах команды `ВыгрузитьЗаказы` нажми на действие — откроется модуль формы.
2. Полностью замени содержимое модуля формы кодом из файла:
   ```
   1c/ВыгрузкаЗаказовВJSON.bsl
   ```
3. Сохрани внешнюю обработку:
   - **Файл → Сохранить** → укажи имя файла, например:
     ```
     C:\1C\Обработки\ВыгрузкаЗаказовВJSON.epf
     ```

---

## Шаг 10. Настроить папку обмена

1. Создай папку на диске:
   ```
   C:\1C\Exchange
   ```
2. Открой внешнюю обработку в режиме **1С:Предприятие**:
   - **Файл → Открыть** → выбери `ВыгрузкаЗаказовВJSON.epf`.
3. В поле **Путь к файлу** укажи:
   ```
   C:\1C\Exchange\orders.json
   ```
4. Укажи период (например, с начала месяца по сегодня).
5. Нажми **Выгрузить заказы**.
6. Проверь, что файл `C:\1C\Exchange\orders.json` создан.

---

## Шаг 11. Подключить к сайту

1. В файле `.env.local` проекта добавь:
   ```env
   ONE_C_EXCHANGE_DIR=C:\1C\Exchange
   ```
2. Перезапусти Next.js:
   ```bash
   npm run dev
   ```
3. Войди в личный кабинет под пользователем с телефоном из `orders.json`.
4. Открой «Мои заказы» — должен появиться заказ из 1С.
5. В админке заказ тоже должен быть виден.

## Возможные проблемы

### «Поле объекта не обнаружено» при выгрузке

Проверь имена объектов в начале процедуры `ВыгрузитьЗаказыНаСервере`:

```1c
ИмяДокументаЗаказ = "ЗаказПокупателя";
ИмяРеквизитаКонтрагент = "Контрагент";
ИмяРеквизитаАдрес = "АдресДоставки";
ИмяТабЧастиТовары = "Товары";
ИмяРеквизитаСтатус = "Статус";
ИмяРеквизитаТелефон = "Телефон";
```

Если ты назвал реквизит по-другому — исправь здесь.

### Заказы не появляются на сайте

1. Проверь, что файл `orders.json` действительно создался.
2. Проверь телефон в файле и в профиле сайта.
3. Убедись, что Next.js перезапущен после изменения `.env.local`.
4. Проверь права доступа к папке `C:\1C\Exchange`.

### Сайт не видит JSON, но видит XLS

Приоритет у JSON выше, чем у XLS. Если JSON есть, но сайт читает XLS — проверь, нет ли ошибки парсинга JSON (например, лишняя запятая).

## Что можно улучшить

- **Автоматическая выгрузка**: добавь обработку в регламентное задание 1С.
- **Обратный обмен**: настрой импорт заказов с сайта в 1С через HTTP API.
- **Больше полей**: добавь в JSON комментарий, способ доставки, скидки и т.д.
