# Интеграция с 1С через JSON-файл

Этот каталог содержит пример настройки обмена заказами между **1С:Предприятием** и сайтом на Next.js через JSON-файл.

## Что получится

1. В 1С хранятся заказы покупателей.
2. Внешняя обработка выгружает их в файл `orders.json`.
3. Сайт читает этот файл и показывает заказы в админке и личном кабинете.

## Формат JSON-файла

```json
{
  "orders": [
    {
      "number": "ЗК-000001",
      "date": "2026-06-17",
      "status": "Новый",
      "total": 4480,
      "clientName": "Исупов Константин",
      "clientPhone": "79081074145",
      "address": "ул. Примерная, д. 1",
      "items": [
        { "name": "Красные тюльпаны", "quantity": 10, "price": 150, "sum": 1500 },
        { "name": "Букет «Весна»", "quantity": 2, "price": 1490, "sum": 2980 }
      ]
    }
  ]
}
```

Поле `status` может быть: `Новый`, `В работе`, `Подтверждён`, `Отправлен`, `Выполнен`, `Отменён`.

## Шаг 1. Создать базу 1С

Создайте новую пустую конфигурацию (или используйте УНФ/УТ/Розницу).

### Минимальная структура для пустой конфигурации

1. **Справочник "Номенклатура"**
   - Наименование (Строка)

2. **Справочник "Контрагенты"**
   - Наименование (Строка)
   - Телефон (Строка)

3. **Документ "ЗаказПокупателя"**
   - Реквизиты шапки:
     - `Контрагент` — СправочникСсылка.Контрагенты
     - `АдресДоставки` — Строка
     - `Статус` — ПеречислениеСсылка.СтатусыЗаказов (или Строка)
   - Табличная часть `Товары`:
     - `Номенклатура` — СправочникСсылка.Номенклатура
     - `Количество` — Число
     - `Цена` — Число
     - `Сумма` — Число

> Если у вас уже есть готовая конфигурация с другими именами — просто подправьте имена в коде обработки.

## Шаг 2. Создать внешнюю обработку

1. Откройте конфигуратор 1С.
2. Создайте новую **внешнюю обработку**.
3. Добавьте управляемую форму.
4. Создайте на форме реквизиты:
   - `ПутьКФайлу` (Строка, 500)
   - `ДатаНачала` (Дата)
   - `ДатаОкончания` (Дата)
   - `СтатусЗаказа` (Строка или ваше перечисление)
5. Добавьте команду формы `ВыгрузитьЗаказы`.
6. Вставьте код из файла [`ВыгрузкаЗаказовВJSON.bsl`](./ВыгрузкаЗаказовВJSON.bsl) в модуль формы.
7. Сохраните обработку как файл `.epf`.

### Важные моменты в коде

В начале процедуры `ВыгрузитьЗакакзыНаСервере` настроены имена объектов:

```1c
ИмяДокументаЗаказ = "ЗаказПокупателя";
ИмяРеквизитаКонтрагент = "Контрагент";
ИмяРеквизитаАдрес = "АдресДоставки";
ИмяТабЧастиТовары = "Товары";
ИмяРеквизитаСтатус = "Статус";
ИмяРеквизитаТелефон = "Телефон";
```

Если в вашей базе объекты называются иначе — поменяйте эти строки.

## Шаг 3. Настроить папку обмена

Сайт ищет `orders.json` в двух местах:

1. В папке проекта: `c:\Users\isupo\pract\1c\orders.json` (удобно для теста)
2. В папке обмена: переменная окружения `ONE_C_EXCHANGE_DIR` (по умолчанию `C:\1C\Exchange`)

### Вариант А. Тестировать локально (без 1С)

Просто отредактируйте файл [`orders.json`](./orders.json) вручную — сайт подхватит его.

### Вариант Б. Рабочий обмен с 1С

1. В обработке укажите путь, например:
   ```
   C:\1C\Exchange\orders.json
   ```
2. Убедитесь, что папка `C:\1C\Exchange` существует и доступна сайту.
3. В файле `.env.local` проекта укажите:
   ```env
   ONE_C_EXCHANGE_DIR=C:\1C\Exchange
   ```
4. Нажмите в обработке **Выгрузить заказы**.

## Шаг 4. Проверить на сайте

1. Перезапустите Next.js-приложение (чтобы подхватил `.env.local`).
2. Войдите в личный кабинет под пользователем с телефоном из `orders.json`.
3. Откройте раздел «Мои заказы» — должен появиться заказ из 1С.
4. В админке (раздел заказов) заказы из 1С появятся рядом с сайтовыми.

## Приоритет источников заказов

Сайт использует такой порядок:

1. **Заказы с сайта** — из `data.json`.
2. **JSON-файл** — `orders.json` из папки обмена или проекта.
3. **XLS-файл** — `orders.xls` (если есть).
4. **CommerceML XML** — `orders.xml`.
5. **HTTP API 1С** — если настроены `ONE_C_BASE_URL`, `ONE_C_USERNAME`, `ONE_C_PASSWORD`.

> Для личного кабинета HTTP API имеет приоритет над файловым обменом. Для админки приоритет у файлового обмена и сайтовых заказов.

## Расширение функциональности

### Автоматическая выгрузка по расписанию

Чтобы 1С сама выгружала заказы, можно:
- Поместить обработку в регламентное задание.
- Или использовать стандартный механизм обмена 1С с выгрузкой в файл.

### Двусторонний обмен

Сейчас реализовано: **1С → сайт**.
Если нужно передавать заказы с сайта в 1С, используйте HTTP API 1С (см. `lib/1c.js`) или настройте импорт заказов в 1С из JSON-файла.

## Поддержка

Если в обработке возникает ошибка — проверьте:
- Имена документа, справочников и реквизитов.
- Что документы проведены.
- Что период (`ДатаНачала` / `ДатаОкончания`) не пустой.
- Что у пользователя есть права на чтение заказов.
