# Интеграция 1С с сайтом (CommerceML)

## Что это

Самый простой способ синхронизации заказов из 1С в веб-приложение без HTTP-сервисов и сложной интеграции. 1С выгружает заказы в XML-файл, сайт читает этот файл и показывает пользователю.

## Как работает

```
┌─────────┐    orders.xml    ┌─────────┐
│   1С    │ ───────────────> │  Сайт   │
│         │  (файл на диске) │         │
└─────────┘                  └─────────┘
```

## Быстрый старт

### 1. Настройте папку обмена

Создайте папку, доступную и 1С, и сайту:

```
C:\1C\Exchange\
```

### 2. В 1С создайте обработку

1. Откройте конфигуратор
2. Файл → Новый → Обработка
3. Добавьте форму с кнопкой "Выгрузить заказы"
4. Вставьте код из файла `ВыгрузкаЗаказов.bsl`
5. Сохраните, обновите конфигурацию

### 3. Настройте сайт

Добавьте в `.env.local`:

```env
# Путь к папке обмена (Windows)
ONE_C_EXCHANGE_DIR=C:\\1C\\Exchange

# Демо-режим (показывает тестовые заказы если файла нет)
ONE_C_USE_DEMO=true
```

### 4. Проверьте

1. В 1С нажмите кнопку "Выгрузить заказы"
2. Убедитесь, что файл `orders.xml` появился в `C:\1C\Exchange\`
3. На сайте зайдите в профиль → "Мои заказы из 1С"

## Как это используется в проекте

### API эндпоинты

| Эндпоинт | Для кого | Описание |
|----------|----------|----------|
| `GET /api/orders/1c` | Пользователь | Заказы по телефону |
| `GET /api/orders/1c/sync` | Админ | Все заказы |

### Код на сайте

```javascript
// lib/commerceml.js — читает XML и парсит заказы
import { parseOrdersFromXML, getOrdersByPhone } from '@/lib/commerceml';

const orders = getOrdersByPhone('79131234567');
// → [{ number: 'ЗК-000001', status: 'В работе', items: [...], ... }]
```

```javascript
// hooks/use1COrders.js — React hook для получения заказов
const { data, isLoading } = use1COrders();
// data.orders — массив заказов из 1С
```

## Автоматизация

### Регламентное задание в 1С

Настройте выполнение каждые 5 минут:

```bsl
Процедура ВыгрузкаЗаказовРегламент() Экспорт
    ВыгрузитьЗаказыВXML("C:\\1C\\Exchange\\orders.xml");
КонецПроцедуры
```

### Сетевой путь

Если 1С и сайт на разных компьютерах:

```
\\server\1c\exchange\orders.xml
```

Или настройте синхронизацию папки через:
- Общую сетевую папку (SMB)
- OneDrive / Google Drive
- Syncthing
- FTP

## Формат XML (CommerceML 2.10)

Сайт понимает структуру:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<КоммерческаяИнформация ВерсияСхемы="2.10" ДатаФормирования="2025-06-18">
  <Документ>
    <Номер>ЗК-000001</Номер>
    <Дата>2025-06-17</Дата>
    <Статус>В работе</Статус>
    <Сумма>1640</Сумма>
    <Контрагенты>
      <Контрагент>
        <Наименование>Петрова Анна</Наименование>
        <Телефон>79131234567</Телефон>
      </Контрагент>
    </Контрагенты>
    <Товары>
      <Товар>
        <Наименование>Красные тюльпаны</Наименование>
        <Количество>5</Количество>
        <Цена>150</Цена>
        <Сумма>750</Сумма>
      </Товар>
    </Товары>
  </Документ>
</КоммерческаяИнформация>
```

## Типовые проблемы

| Проблема | Решение |
|----------|---------|
| "orders.xml not found" | Проверьте путь в `ONE_C_EXCHANGE_DIR` |
| Кодировка кракозябры | Убедитесь, что XML в UTF-8 |
| Телефон не найден | Проверьте формат: 11 цифр, начиная с 7 |
| Пустой список заказов | Проверьте дату в запросе (по умолчанию 30 дней) |

## Альтернатива: HTTP API

Если нужна онлайн-синхронизация без файлов, используйте HTTP-сервис 1С:

```env
ONE_C_BASE_URL=https://1c.example.com/unf/hs/orders
ONE_C_USERNAME=webuser
ONE_C_PASSWORD=secret
```

См. `lib/1c.js` для примера реализации.
